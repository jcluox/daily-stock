# 規格書

這是一個股票分析並生成報告html的python程式。
依據策略條件來選出每日推薦的公司。
透過策略塞選出對應的股票之後，

## github action執行時間

除了手動的以外，自動於每日晚上六點作出分析報告

## 選股時間區分

1, 2, 5, 10, 15, 30日

## 選股策略

依序照下列順序塞選：

1. 成交值前30大
2. 營收創新高

## 實作方式

python程式上傳到github，透過Action生成每日報告

## 呈現方式

可以點擊html上頁面的不同的選股時間區分來查看對應的結果。
每個頁面上面會對每個塞選出的公司，標示出對應的成交值排行、營收創新高幅度、等等資訊。
